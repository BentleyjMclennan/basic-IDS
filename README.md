This is a basic IDS created to detect and alert when an unapproved device joins a network
While running, it logs the network, when an unapproved MAC is detected, it sends the unapproved MAC as an email message to the user

to use this program, it needs your email credentials added in json format to a file named credentials.json, and a MAC whitelist added as whitelist.json, also in a json format

this project was created to learn how to use python, scapy, and some networking fundamentals for my study in cybersecurity
